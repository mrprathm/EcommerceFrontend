# ⚡ ShopX — E-Commerce Frontend

> **Developed by [Pratham Rathod](mailto:prathamrathod200@gmail.com)**  
> React.js | Dark Theme | Full Working E-Commerce UI

A **production-ready React.js frontend** for the ShopX E-Commerce platform with dark premium theme.

---

## 🚀 Tech Stack

| Technology | Purpose |
|---|---|
| React.js 18 | UI Framework |
| React Router v6 | Client-side routing |
| Axios | API calls to Spring Boot backend |
| Context API | Global state (Auth + Cart) |
| CSS3 | Custom dark theme styling |

---

## ✨ Features

- 🏠 **Home Page** — Hero section, categories, featured products, footer
- 🔐 **Auth** — Login & Register with JWT
- 🛍️ **Products** — Browse, search, filter by category, pagination  
- 🛒 **Cart** — Add/remove/update items in real-time
- 💳 **Checkout** — Place order with shipping & payment details
- 📦 **Orders** — Track all your orders with status
- ⚡ **Admin Dashboard** — Manage products, view all orders, update status
- 🌙 **Dark Theme** — Premium dark UI with purple accent

---

## ⚙️ Setup & Run

### Prerequisites
- Node.js 18+
- Spring Boot backend running on port 8080

### Step 1: Install dependencies
```bash
npm install
```

### Step 2: Run the app
```bash
npm start
```
Opens at: **http://localhost:3000**
